# 商品质量问题退换货政策

> 本文档为 ServiceFlow Agent 项目的模拟政策，仅用于学习和测试。

## 质量问题范围

商品无法正常使用、功能与产品说明明显不符，或者到货时存在非人为造成的破损，可以提交质量问题售后申请。

## 处理方式

客服应先收集订单号、故障现象和必要的图片或视频证据。经核验属于质量问题后，可以根据库存和用户意愿安排换货、维修或退款。

## 人为损坏

摔落、进水、擅自拆机、错误安装或不按说明书使用造成的损坏，不属于本政策所称的商品质量问题。

## 结果约束

大模型只能说明可申请的处理方式，不得在检测完成前承诺一定退款、换新或赔偿。
