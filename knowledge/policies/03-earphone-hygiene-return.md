# 耳机类商品退换货特别规则

> 本文档为 ServiceFlow Agent 项目的模拟政策，仅用于学习和测试。

## 未拆封商品

耳机包装和卫生封条均未拆封，且商品页面支持七天无理由退货时，可以按照七天无理由退货政策申请。

## 已拆封商品

入耳式耳机属于个人卫生相关商品。包装或卫生封条拆封后，如无质量问题，不支持七天无理由退货。

## 质量问题例外

已拆封耳机出现单侧无声、无法充电或无法连接等疑似质量问题时，可以申请质量检测。检测确认非人为故障后，按照商品质量问题退换货政策处理。

## 所需信息

申请时应提供订单号、耳机型号、故障现象和已尝试的排查步骤。是否符合退换条件以订单、商品状态和检测结果为准。
